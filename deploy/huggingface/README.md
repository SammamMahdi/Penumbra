# Penumbra

**Know your odds of light before you land.** A lunar south-pole landing planner by Team Tewre Zahbeau for NASA Space
Apps 2026 (Challenge 4: CLPS Lunar Mission Browser).

This Space runs the code from [github.com/SammamMahdi/Penumbra](https://github.com/SammamMahdi/Penumbra); see its
README for how to use the app. After a period without visitors the Space sleeps, and the first visit wakes it in
about a minute.
